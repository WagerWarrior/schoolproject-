STUDENT DROPOUT PROJECT — LEARNING NOTES
Updated: November 21, 2026

WHAT WE ARE BUILDING
We compare enrollment information alone (A, 11 original inputs) against
enrollment plus six first-semester inputs (B, 17 original inputs).
The answer is 1 for recorded Dropout and 0 for Enrolled or Graduate.
Still enrolled does not guarantee eventual graduation. Without dropout dates,
this is retrospective classification, not a validated forecast of future dropout.

WHAT SCIKIT-LEARN DOES
Scikit-learn is a Python library. It provides the learning algorithms, not
pretrained weights for our project. The course instructions explicitly list
scikit-learn as an example Python library under Technical requirements, page 4:
https://eclass.yorku.ca/mod/resource/view.php?id=4550502

HOW LOGISTIC REGRESSION LEARNS
It combines input values with learned weights and an intercept, then converts
the result into a score between 0 and 1. During fit(), an optimizer adjusts the
weights to reduce the training objective (prediction loss plus a penalty).
Our code allows up to 1000 iterations; it may stop sooner after convergence.
We do not choose the learned weights ourselves. They come from fitting our data.
Predicting does not update weights. New learning requires deliberate retraining
using examples with known outcomes. Calibration needs checking before treating
scores as reliable individual probabilities.

PREPARATION
We kept documented unknown categories and valid zeros. We encoded seven nominal
fields with one-hot encoding: separate 0/1 columns for their categories.
We standardized numerical inputs for logistic regression:
scaled value = (original value - training mean) / training standard deviation.
The two existing binary fields remain unchanged. Encoding and scaling are fitted
separately within each cross-validation training fold.

EVALUATION DESIGN
3539 training students; 885 test students held aside. Stratified split, seed 42.
Five-fold cross-validation within training: learn on four parts, validate on one.
Every training student has one validation prediction per model, produced without
training on that row. A and B use the same folds. No test scores computed yet.
Initial cutoff: score >= 0.5 means predict dropout. No tuning yet.

INITIAL RESULTS: VALIDATION ONLY
Mean F1 across folds: baseline 0.0000, logistic A 0.4585, logistic B 0.7017.
Mean accuracy: baseline 67.87%, A 72.34%, B 82.90%.
The baseline always predicts other outcome, so it catches no dropouts.
Average precision and trapezoidal PR-AUC are different summaries and are saved
under separate names. Fold-to-fold standard deviations are in the results file;
they are not confidence intervals or final test results.

DECISION TREE TRAINING — STEP 10
A tree learns which feature and cutoff to ask about, choosing splits that make
the outcome groups more similar. We use the default Gini impurity criterion.
max_depth=3 limits a prediction path to three splits. This is a starting setting,
not an optimized choice or a guarantee against overfitting. No scaling needed.
We trained A and B using the same five folds and cutoff 0.5.
Tree A mean validation F1: 0.5032; accuracy 70.53%.
Tree B mean validation F1: 0.6416; accuracy 80.05%.
Tree B caught 637 dropouts, missed 500, and made 206 false alarms.
Logistic B still has the higher initial F1 (0.7017). Tree A improves recall and
F1 over logistic A, but has lower precision and accuracy. No overall winner
has been selected, and the held-out test group has not been evaluated.
The provisional B tree fitted on all training rows first asks whether courses
passed is <=3.5: because this is a count, that means 3 or fewer versus 4 or more.
This rule is learned, not hand-written, and fold-specific trees may differ.
Next: random forest, then small validation-based tuning and error comparisons.

RANDOM FOREST TRAINING — STEP 11
A random forest combines many decision trees. Our initial forest has 100 trees.
Each tree learns from a random sample of training rows drawn with replacement
(bootstrap sampling): some students may appear more than once in that sample.
Each split considers a random subset of input features. This creates variation
between trees. Scikit-learn averages the trees' class probability estimates;
our code predicts dropout when the average score is at least 0.5.
This can reduce dependence on one tree, but does not guarantee better results.

Simple setup:
RandomForestClassifier(n_estimators=100, random_state=42, n_jobs=-1)
n_estimators is the number of trees; random_state makes the run reproducible;
n_jobs=-1 uses available CPU cores. We left other settings at their defaults,
including unrestricted tree depth. No class weighting or tuning yet.
As with the single tree, we one-hot encode categories but do not scale numbers.
Preprocessing is fitted inside each training fold. We reuse the same five folds
for A and B, and never load test inputs or answers in this training script.

FIRST TUNING COMPARISON — STEP 12
We increased only max_depth from 3 to 5. A student can now go through up to
five questions along a path. The algorithm still chooses the questions itself.
The feature sets, five folds, seed 42 and prediction cutoff 0.5 are unchanged.
Encoding is fitted separately inside each fold. Test inputs/answers not loaded.

Mean validation F1:
                    Depth 3       Depth 5
Enrollment A         0.5032        0.4912
Semester-one B       0.6416        0.6752

B improved in four of five folds, but its F1 spread increased slightly:
fold standard deviation 0.0251 at depth 3 versus 0.0326 at depth 5.
This standard deviation describes variation across folds, not a confidence interval.
B caught 700 dropouts rather than 637, but made 233 false alarms rather than 206.
B mean precision fell from 0.7715 to 0.7516; recall rose from 0.5602 to 0.6158.
A lost F1 at depth 5 even though its accuracy increased slightly.
Conclusion: deeper helped B's F1 but did not help every setup or every metric.
Among these two depths, depth 5 is B's better F1 candidate, and depth 3 is A's.
Logistic B still has the higher initial mean F1, 0.7017. No final selection yet.
Depth-3 files are preserved; depth-5 results and models have separate names.
